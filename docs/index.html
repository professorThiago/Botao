Botao

Leitura de botões para Arduino e ESP32 com debounce resistente a ruído, gestos (clique, duplo, longo, auto-repeat) e callbacks — sem encher o loop() de if e sem delay().

Button handling for Arduino and ESP32 with noise-tolerant debounce, gestures (click, double, long, auto-repeat) and callbacks — no pile of ifs in loop() and no delay().

version 1.3.0 API PT + EN license MIT platforms ESP32 · ESP8266 · RP2040 · AVR framework arduino

    Serial.begin(115200);
    btn.iniciar();

void loop() {
    btn.atualizar();   // SEMPRE no loop(), uma vez por ciclo

    if (btn.clicou())      Serial.println("Clique!");
    if (btn.clicouDuplo()) Serial.println("Duplo!");
    if (btn.segurou())     Serial.println("Longo!");
}

Precisa da outra borda?

Use soltou(). Não inverta o nivelAtivo só para isso: segurou() e estaPressionado() também inverteriam.

Debounce

Os contatos de um botão "quicam" por alguns milissegundos ao fechar e abrir, gerando várias bordas falsas. O debounce filtra isso. A Botao tem dois modos, escolhidos com modoDebounce().

Button contacts "bounce" for a few milliseconds when closing and opening, producing several false edges. Debounce filters that out. Botao has two modes, chosen with modoDebounce().

ModoModeComo funcionaHow it worksQuando usarWhen to use
ModoDebounce::ESTAVEL / DebounceMode::STABLE (padrão)(default) Integrador: soma o tempo em que o pino está no novo nível e desconta o tempo em que volta. Aceita a mudança quando o saldo chega a intervaloDebounce. Glitches curtos não reiniciam a contagem.Integrator: adds the time the pin spends at the new level and subtracts the time it goes back. The change is accepted when the balance reaches intervaloDebounce. Short glitches do not restart the count. Quase sempre. Tolera ruído elétrico, fios longos, relés e cargas próximas.Almost always. Tolerates electrical noise, long wires, relays and nearby loads.
ModoDebounce::IMEDIATO / DebounceMode::IMMEDIATE Aceita a primeira borda na hora e ignora novas bordas por intervaloDebounce ms.Accepts the first edge immediately and ignores new edges for intervaloDebounce ms. Quando a latência zero importa e o sinal é limpo. Com ruído, gera eventos falsos.When zero latency matters and the signal is clean. With noise it produces false events.
cpp
btn.modoDebounce(ModoDebounce::IMEDIATO);
btn.intervaloDebounce(30);    // ms
cpp
btn.setDebounceMode(DebounceMode::IMMEDIATE);
btn.setDebounceTime(30);      // ms

O modo ESTAVEL usa o tempo real entre chamadas de atualizar(), então o debounce continua correto mesmo se o seu loop() for lento.

STABLE mode uses the real time between update() calls, so debounce stays correct even when your loop() is slow.

Clique simples demorando?

Com o clique duplo habilitado, clicou() só dispara intervaloCliqueDuplo ms depois de soltar, porque a biblioteca precisa esperar para saber se virá um 2º clique. Se você não usa clique duplo, chame habilitarCliqueDuplo(false). Para reagir no instante do toque, use pressionou().

Single click feels slow?

With double click enabled, clicked() only fires setDoubleClickTime ms after release, because the library must wait to know whether a 2nd click is coming. If you do not use double click, call enableDoubleClick(false). To react the instant it is touched, use pressed().

Cada método retorna true uma única vez por evento e limpa o aviso automaticamente.

Each method returns true exactly once per event and clears the flag automatically.

Leia cada evento em um só lugar

Como o aviso é limpo na primeira leitura, chamar clicou() em dois pontos do código faz o segundo nunca ver o clique.

Read each event in one place only

Since the flag is cleared on the first read, calling clicked() in two places means the second one never sees the click.

btn.onRelease(fn);       // on release
btn.onClick(fn);         // confirmed single click
btn.onDoubleClick(fn);   // double click
btn.onLongPress(fn);     // long press reached
btn.onLongRelease(fn);   // released after a long press
btn.onAutoRepeat(fn);    // each auto-repeat tick (also enables auto-repeat)

Funções comuns e lambdas são aceitas. Os callbacks são chamados de dentro do atualizar(), então podem usar Serial, digitalWrite etc. normalmente — mas devem ser rápidos.

Plain functions and lambdas are accepted. Callbacks run inside update(), so they may use Serial, digitalWrite and so on — but keep them quick.

cpp
const int LED = 2;

void alternar() { digitalWrite(LED, !digitalRead(LED)); }

void setup() {
    pinMode(LED, OUTPUT);
    btn.iniciar();
    btn.aoClicar(alternar);                                // função comum
    btn.aoSegurar([]() { digitalWrite(LED, LOW); });       // lambda
}
cpp
const int LED = 2;

void toggle() { digitalWrite(LED, !digitalRead(LED)); }

void setup() {
    pinMode(LED, OUTPUT);
    btn.begin();
    btn.onClick(toggle);                                   // plain function
    btn.onLongPress([]() { digitalWrite(LED, LOW); });     // lambda
}

Auto-repeat

Dispara repetidamente enquanto o botão está pressionado. Ótimo para volume, brilho, rolagem de menu ou ajuste de valores.

Fires repeatedly while the button is held. Great for volume, brightness, menu scrolling or value adjustment.

cpp
int volume = 0;

void setup() {
    btn.iniciar();
    btn.configurarAutoRepeat(600, 100);           // 1º disparo após 600 ms, depois a cada 100 ms
    btn.aoAutoRepeat([]() { if (volume < 100) volume++; });
}

void loop() {
    btn.atualizar();
    // alternativa por polling:
    // if (btn.autoRepetiu()) volume++;
}
cpp
int volume = 0;

void setup() {
    btn.begin();
    btn.setAutoRepeat(600, 100);                  // 1st tick after 600 ms, then every 100 ms
    btn.onAutoRepeat([]() { if (volume < 100) volume++; });
}

void loop() {
    btn.update();
    // polling alternative:
    // if (btn.autoRepeated()) volume++;
}

Registrar aoAutoRepeat() já habilita o auto-repeat com os tempos atuais. Para parar: desabilitarAutoRepeat().

Registering onAutoRepeat() enables auto-repeat with the current timings. To stop it: disableAutoRepeat().

Solução de problemasTroubleshooting

Preciso segurar o botão muito tempo para ele responderI have to hold the button a long time before it responds
  • Use a versão 1.1 ou superior: o debounce antigo reiniciava a cada glitch de ruído.
  • Tire os delay() do loop() e chame atualizar() o mais frequentemente possível.
  • Se você usa clicou(), lembre da espera do clique duplo (veja Configuração).
  • Use version 1.1 or later: the old debounce restarted on every noise glitch.
  • Remove delay() from loop() and call update() as often as possible.
  • If you use clicked(), remember the double-click wait (see Configuration).
Cliques falsos ou fantasmasFalse or ghost clicks
  • Use o modo ESTAVEL (padrão). O IMEDIATO não filtra ruído.
  • Aumente intervaloDebounce (ex.: 40–50 ms).
  • No hardware: o pull-up interno do ESP32 é fraco (~45 kΩ). Com fios longos ou cargas por perto, use um pull-up externo de 10 kΩ e um capacitor de 100 nF entre o pino e o GND.
  • Use STABLE mode (default). IMMEDIATE does not filter noise.
  • Increase the debounce time with setDebounceTime() (e.g. 40–50 ms).
  • Hardware: the ESP32 internal pull-up is weak (~45 kΩ). With long wires or nearby loads, add an external 10 kΩ pull-up and a 100 nF capacitor between the pin and GND.

update() is called more than once per pass, or the same event is read in two places. Each flag is consumed on the first read.

Erro de compilação com lambda [this] no Arduino UnoCompile error with a [this] lambda on Arduino Uno

No AVR o callback é um ponteiro de função e não aceita lambdas com captura. Use uma função comum ou uma lambda sem captura.

On AVR the callback is a function pointer and cannot hold capturing lambdas. Use a plain function or a non-capturing lambda.
